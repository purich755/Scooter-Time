# The Scooter Time — демо главной страницы

Прокат ретро-скутеров в центре Казани (Кремлёвская, 21). Концепция: **«Берите время напрокат»**. Через всю страницу проходит ретро-спидометр, который показывает время: живые часы Казани в hero, циферблат тарифов, где вместо км/ч часы аренды, и стрелка, уходящая в ноль в финале.

Чистые HTML + CSS + JS без сборки. Открывается с диска (`index.html`) и как статика с любого хостинга.

## Запуск

```bash
npm install
node tools/serve.mjs 8216
```

Откройте http://localhost:8216/. В общем `.claude/launch.json` конфиг называется `scooter`.

### Как подписать мопед

В `js/config.js` впишите имя: `{ color: 'МЯТНЫЙ', name: 'Мята', img: 'mint' }`. Имя появится на эмалевом брелоке, а вокруг — гравировка «THE SCOOTER TIME · КАЗАНЬ».

### Как поменять часы работы

`hours: { open: '10:00', close: '00:00' }` в `js/config.js`. По этим часам считаются живой статус в hero, мини-часы в шапке и строка в «Как найти».

## Решения, которые отличаются от брифа

- **GSAP и Lenis лежат рядом с сайтом, а не на CDN.** Версии те же (gsap@3.13.0, lenis@1.3.11), файлы скачаны с jsDelivr. Так сайт работает без интернета, а Lighthouse не штрафует за чужой домен. Скрипты подключаются после события `load`: первый экран рисуется сразу, потом оживает.
- **Шрифты локальные** вместо Google Fonts: CSS Google блокировал отрисовку на 2,4 с. Для фолбэков подобран `size-adjust`, поэтому текст не прыгает при подмене шрифта.
- **Карта — своя схема из OpenStreetMap, без iframe Яндекса.** Виджет Яндекса показывает звёзды рейтинга и рекламу, а бриф их запрещает. Схема генерируется `tools/build-map.mjs`.
- **Одометр hero** показывает «ОТКРЫТО · ДО 00:00» или «ОТКРОЕМСЯ В 10:00»: вариант «СЕЙЧАС ОТКРЫТО · ДО 00:00» не помещается между цифрами 24-часового циферблата.
- **Часы в hero 24-часовые:** оранжевая дуга на шкале — часы работы, и если толстая стрелка внутри дуги, значит, прокат открыт.
- Одноразовые появления работают на IntersectionObserver, а ScrollTrigger оставлен для пина тарифов и скраба. Так пересчёт раскладки при загрузке не блокирует поток.

## Проверка (19.10.2026)

- `node tools/interact.mjs 1440` — **19/19**, `node tools/interact.mjs 375` — **20/20**. Проверяется: ключ и фара, тарифы с клавиатуры и мышью (стрелку можно схватить), кнопки тарифов на телефоне, перетаскивание гаража (после перетаскивания лайтбокс не открывается), ключи гаража на наведение и тап, лайтбокс (счётчик, ←/→, фокус-ловушка, Esc), радио (станции и ручка), колода открыток, мобильное меню, alt у всех фото, уникальность id, имена у кнопок, отсутствие форм и горизонтального скролла, чистая консоль.
- `node tools/sweep.mjs 1440|375 [--reduced]` — сплошной проход кадрами плюс контактный лист: без ошибок консоли и без горизонтального скролла.
- `node tools/novendor.mjs` — без GSAP и Lenis страница полностью читаема, приборы рисуются, скрытых блоков нет.
- `node tools/filecheck.mjs` — с диска (file://) шрифты грузятся, ошибок нет.
- **Lighthouse (мобильный, локальный сервер): Performance 85, Accessibility 100, Best Practices 96.** SEO 63 из-за `noindex`: это демо, индексировать его не нужно. LCP — фото hero, CLS 0.009, TBT 0.
- Брейкпоинты проверены на 375, 768, 1024 и 1440; при `prefers-reduced-motion` нет прелоадера, пина, параллакса, помех радио и качания брелоков, всё показано в конечном состоянии.

## Инструменты (`tools/`)

`ya-api.mjs` + `fetch-ya.mjs` — 29 фото Яндекс Карт через внутренний API (браузер ловит капчу, HTTP проходит) · `parse-widget.mjs` — посты VK через `widget_community.php` · `vk-photos.mjs` — фото VK по id со страниц `vk.com/photo-…` (og:image, максимальный размер) · `build-assets.mjs` — цветокоррекция и размеры · `logo.mjs` — круглый логотип из PNG Яндекса · `build-map.mjs` — схема квартала · `gen.mjs` — фрагменты разметки · `fonts.mjs` — локальные шрифты · `snap.mjs`, `sweep.mjs`, `interact.mjs`, `lh.sh`, `longtasks.mjs`, `layoutcost.mjs` — самопроверка · `gauge-lab.html` — стенд прибора.
